# Hackfind Frontend

Next.js dashboard for discovering, filtering, and tracking hackathons.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Views

| Route | Purpose |
|---|---|
| `/discover` | Browse matched hackathons |
| `/my-list` | Joined / interested + deadline countdowns |
| `/filters` | Manage filter profiles |
| `/settings` | Notification channels + agent schedule |
